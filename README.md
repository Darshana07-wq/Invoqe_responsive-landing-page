## ⚙️ Installation and Setup

### Prerequisites

Install [Node.js](https://nodejs.org/) and Git before starting.

### 1. Clone the repository

```bash
git clone https://github.com/Darshana07-wq/Invoqe_responsive-landing-page.git
```

### 2. Navigate to the project folder

```bash
cd Invoqe_responsive-landing-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local URL shown in your terminal, usually:

```text
http://localhost:5173/
```

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

You can deploy this project using platforms such as:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)

Connect your GitHub repository, configure the build command as `npm run build`, and set the output directory to `dist`.
